## 내려받기와 빌드

가장 간단한 방법은 릴리스의 `TravelHitokoto-0.1.7-source.zip`을 풀어 기존 `build_apk.py`로 빌드하는 것입니다. 이 ZIP은 리소스가 이미 모두 포함되어 있습니다.

Git으로 복제한 경우에는 먼저 한 번만 바이너리 리소스를 복원합니다. 로그인된 GitHub CLI가 있으면 다음 명령이 원본 소스 ZIP을 내려받고 복원합니다.

```bash
python3 tools/restore_resources.py
```

또는 릴리스에서 소스 ZIP을 직접 내려받고 경로를 지정합니다.

```bash
python3 tools/restore_resources.py /path/to/TravelHitokoto-0.1.7-source.zip
```

복원기는 ZIP과 각 바이너리의 SHA-256을 확인한 뒤 바이너리만 복원합니다. 수정한 Java·JSON·문서는 덮어쓰지 않습니다. 이후 JDK 17+·Android SDK 35와 Build Tools 35.0.0을 준비하고 `ANDROID_SDK_ROOT`를 지정한 뒤 `python3 build_apk.py`를 실행하세요. 복원한 `signing/travel-test.jks`는 업데이트 설치를 위해 유지합니다.

실제 기기·번역 API·청취 검증은 사용자 담당입니다. GitHub 업로드 작업에서 앱 코드를 수정하거나 빌드를 다시 실행하지 않았습니다.

# 여행 한마디 · Android 0.1.7

오사카·교토·야마자키 여행용 한국어→일본어 말하기 앱. 원래 승인한 베이지·그린 시안을 바탕으로 한 네이티브 Android 앱이다.

## 사용

Android 8.0 이상에서 TravelHitokoto-0.1.7.apk를 기존 앱 위에 설치한다. 주문 → 품목 → 수량 1~10 → 일본어로 말하기. 질문·상품 재고·가격·즐겨찾기도 같은 방식으로 재생한다.

**남성 음성 한 가지로 고정한다. 음성 선택·톤 조절·변조는 없다.** 기존 주문·질문은 앱에 포함된 음성을 인터넷 없이 재생하며 휴대폰의 TTS 설정을 사용하지 않는다. 음성 크레딧: VOICEVOX:玄野武宏 (CV:ガロ). 사용 조건은 NOTICE-VOICE.txt를 참조한다.

천천히 듣기는 같은 남성 음성을 속도만 0.8배로 재생한다. 재생 중 말하기 버튼을 다시 누르면 멈춘다. 미디어 음량을 사용하며 다른 앱으로 이동하면 재생을 멈춘다.

즐겨찾기는 문장과 수량을 함께 기억한다. 기존 버전의 즐겨찾기·마지막 선택은 보존된다. 톱니바퀴는 앱 정보만 표시한다. 한글 발음은 참고용이다.

## 0.1.7 번역 대기

시간 초과를 취소로 잘못 처리해 번역 중에 남을 수 있던 오류를 수정했다. 번역 응답은 최대15초만 기다리고, 응답이 없으면 오류와 재시도 안내를 표시한다. 기다리는 동안 준비 중지 버튼으로 취소할 수 있다. 한글 수량으로 쓴 기본 문장도 바로 찾아 기존 오프라인 음성을 재사용한다. 실제 서비스의 응답 속도는 기기에서 확인하지 않았다.

## 입력하기

즐겨찾기 오른쪽 입력하기 탭에서 한글을 입력하면 아래에 일본어와 한글 발음을 보여준다. 번역하기로 결과를 먼저 확인하거나, 말하기로 번역부터 같은 남성 목소리 재생까지 이어서 실행한다. 입력은 최대140자다.

새 문장 번역에는 인터넷이 필요하다. 번역 문장은 MyMemory로 전송되며, 첫 새 문장 처리 때 공식 음성/읽기 자료 약83MB를 한 번 받는다. 진행 상태를 보여주며 실패하면 재시도할 수 있다. 음성 합성은 기기 안에서 VOICEVOX:玄野武宏(normal style11)로 처리하고, 기기 TTS나 여성 음성으로 대체하지 않는다. 새 문장 음성은64비트 기기에서 지원한다.

최근20개 준비 결과는 기기에 저장해 반복 사용 시 재활용한다. 입력을 바꾸면 이전 결과를 무효화한다. 기존 주문·질문의 오프라인 음성과 즐겨찾기는 유지한다. 번역 서비스의 현재 익명 한도는5,000자/일이며 서비스 오류/한도 초과는 화면에 안내한다. 자세한 소스와 공식 명세 링크는 HANDOFF.md에 있다.

## 화면·콘텐츠

베이지·그린과 수량 캡슐·연초록 문장 패널을 유지하면서 그림 카드는 제거했다. 주문·질문·즐겨찾기는 세로 스크롤 없이 한 화면에 배치하고 글자 버튼 목록을 좌우로 밀어 넘긴다. 보이는 이전/다음 버튼은 없다. 음식·상품/질문 분야 선택창도 한 화면에 몇 개씩 좌우로 넘긴다. 긴 정보와 크게 보여주기도 세로 스크롤을 사용하지 않는다.

상태 표시줄과 내비게이션 여백은 고정 바깥 컨테이너에서 처리한다. 낮은 화면에서는 페이지당 항목 수를 줄이고, 가로 화면에서는 두 열로 배치한다. 검색 중 키보드가 열리면 문장과 말하기를 잠시 숨긴다. 일본어는 남은 높이에 맞추고 긴 한글 발음은 최대 두 줄로 표시한다.

기존 112개 항목에 메뉴·상품 125개와 질문·요청 151항목을 합쳤다. 중복 일본어는 합치며 기존 즐겨찾기 ID를 보존한다. 전체 재생 조합 1,559개를 Ogg로 제공한다. 매장의 당일 메뉴나 재고는 보장하지 않는다.

## 빌드·수정

JDK 17+, Android SDK 35와 Build Tools 35.0.0을 설치하고 ANDROID_SDK_ROOT를 지정한 뒤:

```bash
python3 build_apk.py
```

결과: build/TravelHitokoto-0.1.7.apk. Gradle 없이 javac/aapt2/d8/zipalign/apksigner로 빌드한다. Android Studio 프로젝트도 포함했다. 기존 signing/travel-test.jks를 유지해야 업데이트 설치가 가능하다. 개인용 테스트 서명이며 alias/password는 travel-test다.

콘텐츠 원본은 app/src/main/assets/osaka-content.json이며 기본 빌드가 import_osaka_content.py를 실행한다. 문장을 변경하면 tools/ExportVoice.java로 발화를 추출하고 tools/generate_male_voice.py로 해당 음성을 함께 생성한다. VOICEVOX CORE/VVM 0.17.1, 4.vvm, style 11, Open JTalk 사전과 ffmpeg가 생성 시 필요하다. 생성한 음성과 재생 문장 목록 voice-corpus.json은 소스 ZIP에 포함돼 있다. 앱 빌드 자체에 합성 엔진은 필요 없다.

음성 누락은 tools/check_voice_assets.py에서 빌드 오류로 처리한다. APK와 Gradle의 ogg 무압축 옵션을 유지한다. JNA jar와 jniLibs의 VOICEVOX/ONNX/JNA/libc++ .so도 함께 묶어야 한다. 생성 완료된 고정 음성과 네이티브 라이브러리는 소스 ZIP에 포함돼 있다. 구조와 사용자 결정 사항은 HANDOFF.md, 후속 작업 규칙은 AGENTS.md를 따른다.

## 확인 범위

사용자 요청에 따라 APK 빌드·서명까지만 수행한다. 실제 기기 화면·청취·동작 검증은 사용자가 담당하며 이 버전에서 에뮬레이터나 자동시험을 실행하지 않는다.

자유 입력 번역에는 MyMemory 공식 API와 인터넷을 사용한다. 자체 서버·로그인·마이크 권한은 없다. 문장·즐겨찾기·선택은 기기에 보관한다. Android 시스템 백업 정책은 적용될 수 있다.

삽화는 프로젝트 생성 자산이며 기준 로고는 승인 시안에서 추출했다. UI 기호는 Google Material Icons(Apache 2.0, LICENSE-MaterialIcons.txt)를 사용한다.
